## Sobre o projeto

Neon Surge é um jogo de navegador no estilo Shoot 'Em Up localizado no espaço e com temáticas neon, onde seu objetivo é desviar inimigos e seus projéteis, enquanto mata-os com sua munição.
A dificuldade é baseada em "Waves" que ficam mais difíceis ao longo da partida, mas contendo itens que os inimigos deixam quando morrem, e pode tanto te ajudar quanto te atrapalhar.

### Objetivo do Projeto

O objetivo foi analisar o código-fonte de um jogo existente, compreender seu funcionamento e realizar modificações utilizando conceitos de desenvolvimento de sistemas.

Após as alterações, o projeto foi publicado no GitHub e disponibilizado por meio do GitHub Pages.

## Instalação e Uso

Para começar a jogar, basta apenas fazer o download do arquivo do game disponibilizado neste repositório, abrir usando um navegador web e iniciar!

### Como jogar


#### Computador

| Ação    | Controle |
|---|---  |
| Mover   | W, A, S, D ou setas |
| Mirar   | Mouse |
| Impulso | Espaço |
| Pausar  | P |


#### Celular

O jogo também possui suporte a toque na tela para movimentação.



## Modificações realizadas

- Cores de inimigos mudados;
- Vida do jogador "maximizada";
- Interface com cores modificadas;
- Dificuldade maior (aparece mais inimigos);
- Itens adicionados:
	- Escopeta: idêntica ao triple, mas a cadência é menor;
	- Ultragun: atira um “laser”;
	- Dano: tira 60 de vida.
